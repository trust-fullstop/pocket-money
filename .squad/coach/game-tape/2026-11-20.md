# Game tape — 2026-11-20

## Pay-out overview
The owner is "the bank": each month he pays the kids' Wallet into their real accounts, in euro, while the family counts in rand. Shipped Family → Money → 💸 Pay-out:
- a breakdown that reconciles exactly;
- both currencies shown large, with the ECB rate;
- a "Paid" button that records a full-wallet pay-out (idempotent, locked, undoable), with the euro estimate kept in the note.

- **Kryptonite** caught that the original design would have broken things: tallies would count pay-outs as "lost", the no-savings rule would fire on a paid-out wallet, and partial payments would break the cycle. Pay-outs are now full-only.
- **Vera** caught that the first fix over-corrected: after one pay-out, the no-savings rule could never fire again. Now only the pay-out from the week being closed is added back, with a two-week test.
- **Fumble:** the user's follow-up message ("euro is important") cancelled the first builder before it wrote anything. The relaunch included the new requirement. That cost nothing, but it is another reminder to check list_agents after every user message.
