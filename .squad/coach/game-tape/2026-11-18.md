# Game tape — 2026-11-18

## Public repo: a README for families
Steve made the repo public and asked for a README that people would want to read, especially Christian families who want to teach faith-based stewardship of money, time and resources.

- **Shipped:**
  - A README for families (why the app exists, faith at the heart, the six reflections, how faith is handled, Money school, day to day, privacy, a demo link and 5 demo screenshots).
  - docs/SETUP.md and docs/DEVELOPMENT.md.
  - The MIT license.
  - The Claude key is live for Ask.
- **Play of the game:** Vera read the setup guide as a newcomer would. "Create our family" doesn't exist on a private copy, Ask would fail CORS on anyone else's domain, and the README promised the helper "never receives personal details" while it does send age and the question text. Docs are a product too: every claim is now checked against the code.
- **Privacy sweep before going public:** no secrets ever committed. The second parent's name, the family name and the children's ages/country were removed from tracked files. Old commits still hold a few mentions; rewriting history was offered, not done.
- **Lesson:** when a repo goes public, run a secrets + personal-data scan over files *and* history first, then write docs for the reader you want, not the builder.
